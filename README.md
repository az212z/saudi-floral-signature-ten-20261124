# Saudi Floral Signature — ten independent design previews

Arabic RTL florist and gift-shop previews researched and built on 24 November 2026. These are independent proposals, not owner-approved official stores.

Each site includes an editorial home, curated gallery with filters and saved references, individual arrangement pages, services, occasions, gift-request builder and live greeting-card preview, source/contact page, care guide and printable QR card. No payment, checkout, automatic booking, or automatic message sending.

## Contact and content

Nine sites use publicly evidenced business numbers for WhatsApp links. EVENT ART uses its public Haraj account because a phone could not be verified without login. QR pages also have explicitly labelled WhatsApp sharing links. Opening a request link does not confirm that the merchant received or accepted an order.

Images come from each merchant’s published catalogue or advertisements. Rights remain with their owners; commercial reuse and identity approval must be obtained before an official launch. No original photography, stock availability, pricing, testimonial or authorisation claim is made. See [SOURCES.md](SOURCES.md).

The listed ORAD Dammam domain failed DNS during research; this proposal is a replacement for an unavailable experience, not a claim that ORAD never had a website. Search absence for other prospects is bounded evidence.

## Implementation

Plain static HTML/CSS/JavaScript with local fonts and WebP images. Open through an HTTP server. There is no build dependency or backend. Drafts are saved only when requested, in the current browser; saved selections also use local storage. The previews ask search engines not to index them.
